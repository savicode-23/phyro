Phyro is the new name for Loopline. This alpha keeps opening earlier `.vanim` projects and adds drawing, animation, and export tools for game artwork.

## Highlights

- Open **View → Panels → Document Properties** to set up a rectangular or axonometric grid. Adjust spacing, origin, and angles, and use the toolbar’s **Snap** toggle to place artwork at intersections.
- Use **Shift** to add to a node selection and **Ctrl-click** to make a corner symmetric or switch between symmetric and smooth. Hold **Ctrl** with the Pen to constrain the next segment in 15° increments. The **Path** menu now includes **Stroke to path**.
- Organize clips in animation sets and time drawing layers independently. Select frame ranges in the timeline, and export a set as PNG sequences, individual sprite sheets, or a shared sheet.
- Pair a compatible assistant with the active tab through the bundled CLI. Preview its changes and choose whether to apply an edit or keep a live drawing draft.
- Open **Help → Recent issues** for recent errors and copyable details.

Projects saved with a custom document grid require this version or later.
